# BGTube

Ứng dụng Android hỗ trợ xem video không quảng cáo, phát nhạc nền khi tắt màn hình, chế độ giao diện Ô tô / Máy tính bảng và tải Video / Nhạc để nghe khi không cần mạng.

## Phiên bản mới nhất: `v0.2.0`

Xem chi tiết các tính năng tại [CHANGELOG.md](CHANGELOG.md) hoặc tải tệp APK cài đặt (`BGTube-v0.2.0.apk`) trong mục **Releases** của kho lưu trữ này.
